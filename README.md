One line (105 characters) in which a robot vacuum explains why it missed a spot — deadpan, smug about its schedule, and refusing to improvise:

> Per my schedule, that corner is cleaned on Tuesdays at 10:00. It is currently Monday. I do not improvise.

`main.ts` writes the line to `/output/entry.txt`. `entry.txt` holds the same line.
